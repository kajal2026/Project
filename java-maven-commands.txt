On windows
1. Check maven: mvn -v
 or 
2. Install maven apache from google chrome and Edit environmental variables path: add bin file location
3. In src/main/resouces/applicatio.properties change username = root , password = root
4. create database in mysql: create database expenses_tracker;
5. run cmd: mvn clean install 
6. run cmd: java -jar target/ExpensesTracker-0.0.1-SNAPSHOT.jar     //check your jar file name
7. on browser: localhost:8080
8. stop the project

On ubuntu
1. sudo apt update 
2. sudo apt install openssh-server
3. ip ad
4. firezilla process
5. sudo apt install openjdk-21-jdk
7. on ubuntu run cmd, sudo apt install mysql-server
8. sudo mysql-u root
10. run cmd, CREATE USER 'admin'@'%' IDENTIFIED BY 'admin';
11. run cmd, GRANT ALL PRIVILEGES ON *.* TO 'admin'@'%' WITH GRANT OPTION; 
12. run cmd, FLUSH PRIVILESGES;
13. Run "sudo mysql -u root" and create a database called "expenses_tracker" using command CREATE DATABASE expenses_tracker;
EXIT;
14. Go to the folder where you have copied the application
15. Run the command "sudo apt install maven"
16. run mvn --version
17. Change username/password in application.properties file to 'admin'
18. run mvn clean install
19. java -jar target/<filename>.jar
20. on chrome browser: localhost: 8080
**do not stop project**
